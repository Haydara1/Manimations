# Mathematical & Scientific Visualizations

A collection of mathematical and scientific visualizations created with [Manim](https://www.manim.community/), the mathematical animation engine for Python.

This repository brings abstract ideas to life through animations, exploring concepts from mathematics, physics, and beyond.

## About

The goal of this project is to make complex concepts easier to understand through visual intuition, experimentation, and mathematical rigor.

The repository serves as a growing collection of animations, experiments, and visual explanations covering topics such as:

- **Mathematics** — calculus, linear algebra, geometry, and mathematical proofs.
- **Physics** — mechanics, electromagnetism, and wave phenomena.
- **Quantum Mechanics** — quantum states, operators, and quantum phenomena.
- **Algorithms & Other Topics** — visual explanations of interesting computational and scientific ideas.

*Topics listed above describe the project's scope and may include planned work.*

## Getting Started

### Prerequisites

Install Python and Manim Community Edition. Follow the [official Manim installation guide](https://docs.manim.community/en/stable/installation.html) for platform-specific instructions.

### Running an Animation

Clone the repository:

```bash
git clone GitHub.com/Haydara1/Manimations
cd Manimations
```

Install Manim if you haven't already:

```bash
pip install manim
```

Render a scene from a Python file:

```bash
manim -pql path/to/file.py SceneName
```

Replace `path/to/file.py` with the relevant file path and `SceneName` with the name of the Manim scene you want to render.

- `-p` opens the rendered video after completion.
- `-ql` renders at low quality for faster previews.
